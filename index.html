Garden map

Drag the map to explore. Settings contains Return to center, Toggle grid, and the current coordinates display.

Task lists

Create up to three quick-access task lists in the menu. Additional lists are available inside Task Lists. You can open multiple lists at once.

Tasks

Tasks earn coins when completed. A new task defaults to 5 coins. Completing a task with the same exact title completes matching tasks in every list.

Drag and drop

Drag the handle next to an unfinished task to move it inside a list or to another open list. If ordering does not save, run the task order SQL update.

Shop

Open Shop, choose an item, then select a tile. Clicking an existing item removes it and refunds 50% of its shop price.

Habits and goals

Open Habits or Goals from Task Lists. Habits build streak bonuses up to +7 coins. Goals are bigger milestones with larger rewards.
